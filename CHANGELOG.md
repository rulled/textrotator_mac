# Changelog

All notable changes to TextRotator will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.0.3] - 2026-10-18

### Fixed / Исправления
- **Интерактивность меню статус-бара**: устранена деаллокация `StatusBarController` при чистом фоновом запуске без открытых окон (все пункты меню в Menu Bar становились серыми и недоступными).
- **Прямое обновление состояния меню**: исключено деструктивное пересоздание `NSMenu` внутри делегата `menuWillOpen`, что нарушало цикл обработки событий AppKit.

## [1.0.2] - 2026-10-18

### Added / Новые возможности
- **Импорт и экспорт конфигурации**: полная двусторонняя совместимость с оригинальным Windows TextRotator (JSON-бэкап папок, текстов, горячих клавиш и настроек) через меню «Настройки».
- **Автоматический запрос Универсального доступа (Accessibility)**: при первом запуске приложение корректно регистрируется в системном списке «Конфиденциальность и безопасность».
- **Чистый первый запуск**: удалены тестовые демонстрационные данные — приложение стартует с чистой локальной базы.

### Changed / Улучшения
- **Производительность и точность поиска**: потокобезопасный кэш нормализации строк (`NormalizeCache`), фильтрация шума раскладки для односимвольных запросов.
- **Светлая модальная карточка настроек**: обновлён материал карточки (`.thinMaterial`) для сохранения естественной яркости и контрастности над тёмной подложкой.
- **Синхронная плавная анимация**: модальное окно настроек и системный тайтлбар затемняются и закрываются синхронным переходом с плавной анимацией альфы.

### Fixed / Исправления
- **Устранён джиттер строк папок**: фиксированная высота строки (28pt) и постоянная геометрия скрытых кнопок действий убрали микросдвиги при наведении курсора.
- **Равномерное затемнение окна и тайтлбара**: устранён артефакт двойного затемнения в левом верхнем углу (под кнопками светофора) в светлой теме.
- **Устранена белая вспышка тайтлбара**: пре-созданный слой затемнения предотвращает пересборку системного blur-графа при вызове настроек.

## [1.0.1] - 2026-10-18
### Added / Новые возможности
- **Автоматическое обновление (In-App Auto-Update)**: встроенная проверка новых версий через GitHub Releases, нативное диалоговое окно обновления в стиле Liquid Glass, загрузка и перезапуск приложения в один клик.
- **Проверка обновлений вручную**: добавлены пункты «Проверить обновления…» в контекстное меню статус-бара и в панель настроек.
- **Опция «Пропустить версию»**: возможность отложить обновление или скрыть уведомление для текущей минорной версии.
- **Сборщик пакетов и инсталляторов (DMG & Zip)**: автоматизированное создание красивого DMG-образа с кастомной стрелкой установки в `/Applications` и компактного Zip-архива для CI/CD.
- **Обязательный контроль версий**: скрипты валидации `check_changelog.sh` и извлечения `extract_changelog.sh` для автоматического формирования релизов в GitHub Actions.

### Changed / Улучшения
- **Панель настроек (Settings Modal)**: переработана кнопка закрытия (единый круглый элемент управления в стиле Apple), поддержано закрытие по клику вне модального окна.
- **Сохранение конфигурации**: гарантированное сохранение назначенных горячих клавиш и режима курсора в UserDefaults.
- **Интерфейс Liquid Glass**: тонкая настройка материалов размытия и теней для безупречного отображения на macOS 15 Sequoia и macOS 14 Sonoma.

### Fixed / Исправления
- Исправлено поведение повторного вызова окна настроек из Menu Bar.
- Устранена задержка фокуса при быстром переключении между поиском сниппетов и переводом.

## [1.0.0] - 2026-10-18

### Added / Первоначальный релиз
- **Дизайн-система Liquid Glass**: полупрозрачный парящий интерфейс с адаптивными акцентами в стиле macOS Sequoia.
- **Быстрые сниппеты (Quick Snippets)**: менеджер сниппетов с древовидной структурой папок, поддержкой drag-and-drop сортировки и быстрым поиском.
- **SQLite FTS5 база данных**: локальное хранилище шаблонов с полнотекстовым поиском и высокой производительностью.
- **Двухсторонний переводчик (Translation Router)**: мгновенный перевод выделенного текста с поддержкой Google Translate и Яндекс Переводчика.
- **Глобальные горячие клавиши**: регистрация системных хоткеев через Carbon / AppKit для мгновенного вызова оверлея.
- **Слежение за курсором и выделением**: умный перехват активного фрагмента текста через Accessibility API.
- **Меню статус-бара**: легковесный агент в Menu Bar macOS (LSUIElement) с быстрым доступом ко всем функциям.
